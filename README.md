# AI / ML / GenAI Workspace

A unified project for **chatbots**, **AI assistants**, **RAG**, **agents**, **MCP**, **REST API (Swagger)**, and **MiniGPT** (from-scratch GPT + Llama fine-tuning).

## Prerequisites

- Python 3.10+
- [uv](https://docs.astral.sh/uv/) package manager

Install uv:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Setup

```powershell
cd C:\MY_SPACE\AI_ML_GENAI

# Create venv and install all dependencies
uv sync --extra dev

# Configure environment
copy .env.example .env
```

## Usage

### 1. Add documents (for RAG)

Place PDF, `.txt`, or `.md` files in `data/raw/`.

### 2. Add a model (optional)

See the full **[Models Guide](models.md)** for download links, hardware tips, and all usage modes.

- **API (easiest):** set `USE_API_LLM=true` and `OPENAI_API_KEY` in `.env`
- **Local GGUF:** download a `.gguf` to `models/`, run `uv sync --extra local-llm`, set `LLM_MODEL_PATH` in `.env`

### 3. Build vector index (RAG)

```powershell
uv run python ingest.py
```

### 4. Run main app (all modes)

```powershell
uv run streamlit run app.py
```

Modes in the sidebar: **Chatbot**, **AI Assistant**, **RAG Q&A**, **Agent**.

### 5. Run REST API (Swagger)

```powershell
uv run python api_server.py
```

Open **http://localhost:8080/docs** for Swagger UI. See [docs/api.md](docs/api.md).

### 6. Run MCP server

```powershell
uv run python mcp_server/server.py
```

Point Cursor or other MCP clients to `mcp_server/config.json`.

### 7. Run tests

```powershell
uv run pytest
```

## Module overview

| Module | Purpose |
|--------|---------|
| `rag/` | Document ingestion, embeddings, FAISS, RAG chains |
| `agents/` | Tool-calling agents and multi-step workflows |
| `mcp_server/` | MCP server/client for external tool integration |
| `chat/` | Chatbot and assistant with conversation memory |
| `app.py` | Unified Streamlit UI for all modes |
| `api_server.py` | FastAPI REST API with Swagger at `/docs` |
| `minigpt/` | From-scratch GPT + Llama fine-tuning — see [docs/minigpt.md](docs/minigpt.md) |
| `ingest.py` | One-command vector DB build |

## Common uv commands

```powershell
uv sync --extra dev          # Core dependencies
uv sync --extra local-llm    # Add local GGUF support (optional)
uv add <package>          # Add a new dependency
uv run python ingest.py   # Run scripts in project venv
uv run pytest             # Run tests
uv run streamlit run app.py
uv run python api_server.py   # REST API + Swagger at :8080/docs
uv run python scripts/generate_pdfs.py   # Regenerate docs/pdf/*.pdf
```

## Notes

- `vector_db/` is generated by `ingest.py` and ignored by Git.
- Large model files in `models/` are ignored by Git.
- Agents work best with API LLMs that support tool calling (`USE_API_LLM=true`).
- See [Health Check & Setup Status](docs/health-check-and-setup.md) for what's working and how to finish LLM setup.
