# AI RAG Assistant

A generic **Retrieval-Augmented Generation (RAG)** project for building chatbots and AI assistants over your own documents. Works with any domain — not limited to medical or any single use case.

## Features

- Document ingestion (PDF, TXT, Markdown)
- FAISS vector store with sentence-transformer embeddings
- Local LLM via GGUF (LlamaCpp) or API LLM (OpenAI)
- Streamlit chat UI
- Experiment notebook for tuning

## Project structure

```
AI-RAG-Assistant/
├── app.py              # Streamlit chat UI
├── ingest.py           # Build/update FAISS index
├── config/             # Settings and paths
├── data/raw/           # Source documents
├── models/             # Local GGUF weights
├── vector_db/          # Generated FAISS index
├── rag/                # RAG pipeline modules
├── tests/
└── notebooks/
```

## Prerequisites

- Python 3.10+
- [uv](https://docs.astral.sh/uv/) package manager

Install uv (if needed):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Setup

```powershell
cd AI-RAG-Assistant

# Create virtual environment and install dependencies
uv sync --extra dev

# Copy environment template
copy .env.example .env
```

## Usage

1. **Add documents** to `data/raw/` (PDF, `.txt`, or `.md` files).

2. **Add a local model** (optional): place a GGUF file in `models/` and set `LLM_MODEL_PATH` in `.env`.  
   Or set `USE_API_LLM=true` and `OPENAI_API_KEY` to use an API model.

3. **Build the vector index:**

```powershell
uv run python ingest.py
```

4. **Run the chat UI:**

```powershell
uv run streamlit run app.py
```

5. **Run tests:**

```powershell
uv run pytest
```

## Configuration

Edit `.env` (see `.env.example`):

| Variable | Description |
|----------|-------------|
| `EMBEDDING_MODEL` | HuggingFace embedding model |
| `LLM_MODEL_PATH` | Path to local GGUF model |
| `USE_API_LLM` | `true` to use OpenAI instead of local LLM |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | Text chunking for RAG |
| `TOP_K` | Number of chunks retrieved per query |

## Common uv commands

```powershell
uv add <package>          # Add a dependency
uv sync                   # Install/sync all dependencies
uv run python ingest.py   # Run scripts in the project venv
uv run pytest             # Run tests
```

## Notes

- `vector_db/` is generated by `ingest.py` and ignored by Git.
- Large model files in `models/` are ignored by Git — download weights separately.
- For GPU-accelerated local inference, install `llama-cpp-python` with CUDA support per its documentation.
